# Idea

Written at stage 0 (`kickoff`). The owner confirms it.

## Problem

Я весь день сижу за компьютером и почти не встаю. Забываю размяться, вовремя поесть, потренироваться и позаниматься теорией на права. Нужно десктопное приложение для Windows, которое само напоминает об этом в течение дня: раз в час встать и подвигаться, а ещё поесть, потренироваться и позаниматься теорией на права.

## Who it is for

В первую очередь я сам. Готовый установщик для Windows лежит в GitHub Releases для всех, кто захочет скачать, без поддержки и гарантий. Каждая установка служит одному человеку: аккаунтов и сервера нет. Это проект для портфолио, репозиторий публичный.

## Out of scope

- Первый релиз делает только напоминания. Позже, не в первом релизе: данные активности с телефона и их анализ через Claude, проверка по веб-камере, как я сижу.
- В первом релизе приложение хранит только настройки, локально, и не выходит в сеть.
- Автообновления нет: новую версию скачивают с GitHub Releases вручную.
- Не нужны совсем: macOS (решено на discovery: только Windows), публикация в Steam, подпись кода (без сертификата Windows при установке будет предупреждение SmartScreen) и Linux.
- Electron не обязателен: довод «можно будет выпустить в Steam» отпал, и на discovery владелец склонился к стеку легче Electron. Стек выбирается на этапе decide.

## Process level

Уровень lite. Его условие: «one user, no money or personal data, 1 to 3 epics».

- Один пользователь: каждая установка служит одному человеку, без аккаунтов, общего сервера и базы данных. То, что установщик может скачать любой, не делает пользователей общими.
- Без денег и персональных данных: денег нет, хранятся только настройки, локально, без сети.
- От 1 до 3 эпиков: первый релиз делает только напоминания.
- Признаков standard (пользователи с аккаунтами, база данных, auth, деплой) и full (несколько сервисов, realtime, платежи, AI) в первом релизе нет. Данные с телефона, анализ через Claude и веб-камера принесут персональные данные и AI: когда до них дойдёт, уровень надо пересмотреть.
