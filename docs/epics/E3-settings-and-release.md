# E3 - Окно настроек и готовность к релизу

Goal: напоминания настраиваются в окне без правки файла, README объясняет установку без подписи, а установка и расход памяти проверены на ПК владельца.
Depends on: E2
Risk class: normal
ADR: ADR-0001, ADR-0002

## Acceptance criteria

- [ ] E3-AC1: Пункт «Настройки» в меню трея открывает окно со списком напоминаний. В нём можно добавить напоминание любого из двух видов, переименовать его, включить или выключить, удалить; у вида «каждые N минут» менять интервал, у вида «в заданное время» менять время и дни недели.
- [ ] E3-AC2: Сохранённые изменения сразу действуют на расписание и остаются после перезапуска приложения.
- [ ] E3-AC3: Неверный ввод не сохраняется, и окно показывает, что исправить: интервал 0 или пустой, время вне 00:00–23:59, ни одного выбранного дня, пустое название.
- [ ] E3-AC4: Окно настроек полностью работает с клавиатуры, у каждого поля есть доступное имя; весь интерфейс приложения на русском, строки лежат в ресурсах .resx.
- [ ] E3-AC5: README описывает, что делает приложение, как его установить, шаги SmartScreen («Подробнее», затем «Выполнить в любом случае»), что при включённом Smart App Control приложение не запустится, что без включённых уведомлений Windows напоминания не придут, и что поддержка идёт через GitHub Issues без гарантий (A-2, R-1).
- [ ] E3-AC6: Установщик с пометкой «скачан из интернета» на ПК владельца ставится через «Подробнее» и «Выполнить в любом случае» без запроса UAC, и приложение запускается (A-2).
- [ ] E3-AC7: После часа работы в трее с закрытым окном настроек приложение занимает до 50 МБ памяти (частный рабочий набор, как в Диспетчере задач) и около 0% CPU (A-4).
- [ ] E3-AC8: Установка новой версии поверх работающей: установщик закрывает работающее приложение или просит закрыть его, ставит новую версию без запроса UAC, и после этого settings.json и выключенный пользователем автозапуск сохраняются (A-5).
- [ ] E3-AC9: Удаление, пока приложение работает (а с автозапуском оно работает всегда): деинсталлятор закрывает приложение или просит закрыть его, и после удаления нет ни процесса приложения, ни установленных файлов, ни ярлыка, ни ключей автозапуска и AppUserModelID; %APPDATA%\move-reminder остаётся.

## Out of scope

Английский интерфейс, история и статистика напоминаний, автообновление, подпись кода (docs/DISCOVERY.md, Non-goals).
