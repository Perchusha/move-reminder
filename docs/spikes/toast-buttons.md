# Spike: Уведомления с кнопками у неподписанного приложения

## Hypothesis

Неподписанное приложение WinForms на .NET 10, поставленное установщиком NSIS на пользователя без прав администратора, показывает на Windows 11 x64 через встроенный WinRT (Windows.UI.Notifications, без Windows App SDK) уведомление с кнопками «Отложить» и «Закрыть», и каждое нажатие доходит до работающего приложения, и с баннера, и из центра уведомлений. При включённом «Не беспокоить» уведомление не теряется, а оказывается в центре уведомлений.

## Criterion

Committed before any prototype code, and never changed after that commit. Each row names what is measured, how, and the number that counts as success.

| Metric | How it is measured | Success when |
| --- | --- | --- |
| Установка без прав администратора | Владелец запускает собранный установщик NSIS и считает запросы UAC | 0 запросов UAC |
| Доставка уведомлений | Прототип показывает 10 уведомлений с двумя кнопками и сразу пишет в журнал число своих уведомлений в истории (ToastNotificationHistory); скрипт measure.ps1 считает | 10 из 10 |
| Нажатия с баннера | Владелец нажимает кнопку на 5 баннерах (3 «Отложить», 2 «Закрыть»); прототип пишет каждое нажатие с id уведомления и кнопкой в журнал; measure.ps1 сверяет с ожидаемым | 5 из 5 с верной кнопкой |
| Нажатия из центра уведомлений | Владелец ждёт, пока 5 других баннеров уйдут в центр уведомлений, и нажимает кнопки там (3 «Отложить», 2 «Закрыть»); сверка той же командой | 5 из 5 с верной кнопкой |
| Уведомление при «Не беспокоить» | Владелец включает «Не беспокоить», прототип показывает 1 уведомление и пишет в журнал число своих уведомлений в истории; measure.ps1 считает | 1 из 1 в центре уведомлений |
