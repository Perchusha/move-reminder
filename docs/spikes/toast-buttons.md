# Spike: Уведомления с кнопками у неподписанного приложения

- Assumption: A-1
- Branch: spike/toast-buttons
- Date: 2026-11-13
- Outcome: not confirmed
- Prototype: 5136b67180cff3bbff49d17ad848fabbb8d97dfd
- Follow-up: R-1

## Hypothesis

Неподписанное приложение WinForms на .NET 10, поставленное установщиком NSIS на пользователя без прав администратора, показывает на Windows 11 x64 через встроенный WinRT (Windows.UI.Notifications, без Windows App SDK) уведомление с кнопками «Отложить» и «Закрыть», и каждое нажатие доходит до работающего приложения, и с баннера, и из центра уведомлений. При включённом «Не беспокоить» уведомление не теряется, а оказывается в центре уведомлений.

## Conclusion

Not confirmed. Установка без прав администратора (0 запросов UAC), доставка (10 из 10) и «Не беспокоить» (1 из 1 в центре уведомлений, без баннера) прошли критерий. Нажатия с баннера (3 из 5) и из центра уведомлений (0 из 5) его не прошли. По баннерам промах дала ошибка при замере: все пять нажатий дошли до приложения, но «Закрыть» ни разу не нажали. Центр уведомлений провалился по существу: неупакованное приложение без COM-активатора получает в центре уведомлений уведомление без кнопок, так что «Отложить» и «Закрыть» оттуда недоступны. Кроме того, до теста у владельца уведомления Windows были выключены целиком. Значит, напоминание, которое опирается только на системное уведомление, до него не дошло бы вовсе. Сырые данные лежат на ветке spike/toast-buttons в prototype/toast-buttons/results. Владелец принял риск: R-1 в docs/RISKS.md.
