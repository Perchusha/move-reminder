# Discovery

Written at stage 1 (`discovery`). Each section is checked before stage 2 starts.

## Problem and user

Пользователь — разработчик, который весь день сидит за компьютером на Windows 11 и почти не встаёт. Он забывает размяться, вовремя поесть, потренироваться и позаниматься теорией на права. Задача приложения: самому напоминать об этом в течение дня. Раз в час нужно встать и подвигаться, а в заданное время поесть, потренироваться и заняться теорией. Сейчас он не пользуется ничем: ни будильниками, ни часами, ни приложениями, поэтому просто забывает. Приложение делается в первую очередь для себя. Установщик бесплатно лежит в GitHub Releases для всех желающих, без поддержки и гарантий. Каждая установка служит одному человеку: без аккаунтов, без сервера, без сети. Это проект для портфолио, репозиторий публичный.

## Scenarios

- Первый запуск: скачиваю установщик из GitHub Releases и ставлю его на Windows 11 x64, предупреждение SmartScreen о неподписанном приложении обхожу вручную. После запуска приложение садится в трей и сразу, без настройки, начинает раз в час напоминать встать и подвигаться.
- Ежечасное напоминание о движении: через час работы приходит системное уведомление «Встань и подвигайся». Его можно закрыть или отложить на несколько минут, и следующий час отсчитывается заново. Если компьютер спал или экран был заблокирован, после возвращения отсчёт начинается сначала, без пачки пропущенных уведомлений.
- Напоминания о еде, тренировке и теории на права: в настройках задаю время и дни для каждого, например обед в 13:00, тренировку в 19:00 по пн, ср и пт, теорию в 20:00. В это время приходит системное уведомление.
- Настройка: меняю интервал напоминаний о движении, включаю и выключаю каждое напоминание, правлю время и дни. После перезапуска приложения всё сохранилось.
- Пауза: перед созвоном ставлю напоминания на паузу на час или до конца дня. Пауза снимается вручную или заканчивается сама.
- Автозапуск: после перезагрузки компьютера приложение запускается само и продолжает напоминать.

## Non-goals

- Данные активности с телефона и их анализ через Claude: позже, не в первом релизе.
- Проверка по веб-камере, как я сижу: позже, не в первом релизе.
- Сеть: приложение никуда не ходит. Нет аккаунтов, сервера, синхронизации и аналитики.
- История и статистика: приложение не хранит, что выполнено или пропущено, хранит только настройки.
- Учебные материалы: по теории на права приложение только напоминает, билетов и тестов внутри нет.
- Автообновление: новую версию скачивают с GitHub Releases вручную.
- Steam, подпись кода, macOS, Linux и мобильное приложение: не нужны совсем.

## Assumptions by risk

| ID | Assumption | Risk | How to check it |
| --- | --- | --- | --- |
| A-1 | Неподписанное приложение, установленное из GitHub Releases, надёжно показывает на Windows 11 x64 системное уведомление с кнопками «Отложить» и «Закрыть», и нажатие кнопки доходит до приложения. Поведение при включённом «Не беспокоить» (в том числе автоматическом в полноэкранном режиме) известно и устраивает владельца | high | Spike: собрать неподписанный установщик, поставить на Windows 11 x64, вызвать 10 уведомлений с двумя кнопками. Результат: показаны 10 из 10, дошли 10 из 10 нажатий, поведение при «Не беспокоить» записано |
| A-2 | Неподписанный установщик удаётся поставить и запустить на Windows 11: SmartScreen пропускает его через «Подробнее» и «Выполнить в любом случае», а Smart App Control его не блокирует | high | Документация Microsoft по SmartScreen и Smart App Control, затем проверка на ПК владельца: посмотреть статус Smart App Control в «Безопасность Windows» и поставить неподписанную сборку. Результат: приложение запустилось, шаги обхода записаны для README |
| A-3 | Приложение узнаёт о сне, пробуждении, блокировке и разблокировке Windows и не выдаёт после них пачку пропущенных уведомлений. Отсчёт часа начинается заново, а напоминание на время дня, пропущенное во сне, ведёт себя так, как решит владелец | medium | Прототип: уйти в сон на 2 часа так, чтобы на это время пришлось напоминание, потом заблокировать экран на 10 минут. Результат: пачки уведомлений нет, события сна и блокировки видны в консоли прототипа, отсчёт идёт с момента возвращения |
| A-4 | Приложение в трее весь день потребляет заметно меньше ресурсов, чем типичное приложение на Electron | medium | На decide замерить кандидатов в стек: память и CPU в Диспетчере задач после часа простоя в трее. Стек выбирается с учётом замера, порог фиксируется там же |
| A-5 | Автозапуск при входе в Windows включается без прав администратора и переживает установку новой версии поверх старой. Настройки в профиле пользователя тоже сохраняются | low | Документация выбранного стека об автозапуске, затем проверка: включить автозапуск, перезагрузить ПК, поставить следующую версию поверх. Результат: приложение стартовало само, настройки на месте |

IDs run `A-1`, `A-2`, and so on. Risk is one of pitwall's `discovery.riskOrder`, highest first. The riskiest goes to a spike.
