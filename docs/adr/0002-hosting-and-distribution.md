# ADR-0002: Хостинг и дистрибуция: установщик NSIS на пользователя в GitHub Releases

- Status: accepted
- Date: 2026-11-13
- Class: one-way
- Decided by: owner

## Context

Сервера нет. Установщик лежит в GitHub Releases публичного репозитория, сборка идёт в GitHub Actions, подписи кода нет и не будет (docs/DISCOVERY.md: Hosting, Monthly budget). Нужен формат, который ставится без прав администратора и даёт Windows то, что нужно уведомлениям неупакованного приложения: ярлык в меню «Пуск» и AppUserModelID (A-1). Сначала владелец выбрал portable .zip, затем переменил решение на рекомендованный NSIS.

## Options

| Option | Pros | Cons | Maturity | Cost | Lock-in | Source |
| --- | --- | --- | --- | --- | --- | --- |
| NSIS, установщик на пользователя (.exe) | Ставит без прав администратора в %LOCALAPPDATA%; создаёт ярлыки и удаляет их при деинсталляции; Tauri 2 собирает его встроенным бандлером, для других стеков пишется скрипт NSIS; лицензия zlib/libpng совместима с MIT | SmartScreen предупреждает на каждой новой версии (More info, затем Run anyway); при включённом Smart App Control запуск блокируется; ставит ли NSIS AppUserModelID на ярлык: unknown | NSIS 3.13 от 2026-09-27 | 0 | Низкий: только конфигурация установщика | https://v2.tauri.app/distribute/windows-installer/ |
| MSI (WiX Toolset), на пользователя | Windows Installer умеет ставить per-user без UAC; Microsoft приводит WiX как способ поставить ярлык с AppUserModelID | По умолчанию per-machine; бинарники WiX под EULA Open Source Maintenance Fee; тот же SmartScreen и Smart App Control; собирается только на Windows | WiX 7.0.1 от 2026-10-26, мажорная версия примерно раз в год | 0 при освобождении от OSMF (выручка до 10000 USD в год) | Средний: разметка .wxs привязана к WiX | https://learn.microsoft.com/en-us/windows/win32/msi/single-package-authoring |
| Portable .zip | Нет установщика и инструмента упаковки | Нет деинсталлятора; ярлык, автозапуск и регистрацию уведомлений приложение ставит и убирает само; Microsoft советует ставить ярлык с AppUserModelID установщиком, а не кодом приложения | Инструмента нет | 0 | Минимальный | https://learn.microsoft.com/en-us/windows/win32/shell/enable-desktop-toast-with-appusermodelid |

## Decision

Установщик NSIS на пользователя (.exe, без прав администратора) с деинсталлятором. Он собирается на Windows-раннере GitHub Actions и выкладывается в GitHub Releases. Staging на уровне lite заменяет локальная сборка того же установщика. Владелец выбрал рекомендацию: без прав администратора, с деинсталлятором, лицензия совместима с MIT, затрат нет, EULA с платой нет.

## Consequences

- Установщик кладёт ярлык в меню «Пуск» текущего пользователя, а деинсталлятор убирает ярлык, ключ автозапуска HKCU Run и регистрацию уведомлений. Настройки в %APPDATA%\move-reminder (ADR-0001) по умолчанию остаются.
- Ставит ли NSIS AppUserModelID на ярлык, неизвестно. Если выбранному фреймворку он нужен для уведомлений, это решается в спайке по A-1 (плагином NSIS или кодом приложения).
- По A-2 документация Microsoft показала: SmartScreen предупреждает о неподписанном файле на каждой новой версии, а Smart App Control блокирует неподписанное приложение, и исключение для одного приложения сделать нельзя. На ПК владельца Smart App Control выключен (реестр, VerifiedAndReputablePolicyState = 0, 2026-11-13). У пользователей с включённым Smart App Control приложение не запустится; README говорит об этом и о шагах в SmartScreen. Установку на ПК владельца ещё нужно проверить.
- Стандартные раннеры GitHub Actions бесплатны для публичного репозитория (docs.github.com), так что ограничение «0 в месяц» соблюдено.
- Пересмотр: формат меняется в любом релизе. Цена: новый конфиг сборки и одно ручное удаление старой версии у пользователя.
