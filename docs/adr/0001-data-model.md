# ADR-0001: Модель данных: список напоминаний двух видов

- Status: accepted
- Date: 2026-11-13
- Class: one-way
- Decided by: owner

## Context

Приложение хранит только настройки напоминаний, локально и без сети (docs/DISCOVERY.md, Personal data). Нужно решить, как описываются напоминания: от этого зависят окно настроек, формат файла на диске и то, во что обойдётся новый вид напоминания. Хранение одинаково во всех вариантах: один JSON-файл с полем `schemaVersion` в `%APPDATA%\move-reminder\`, без базы данных.

## Options

| Option | Pros | Cons | Maturity | Cost | Lock-in | Source |
| --- | --- | --- | --- | --- | --- | --- |
| A. Фиксированный набор: «Движение» (каждые N минут), «Еда», «Тренировка», «Теория» (время и дни недели) | Самое простое окно настроек, меньше всего кода и тестов | Новое напоминание выходит только с новой версией приложения | JSON, стандарт RFC 8259 | Самая низкая | Низкий: по schemaVersion можно мигрировать в B | https://www.rfc-editor.org/rfc/rfc8259 |
| B. Список двух видов: «каждые N минут» и «в заданное время по дням недели»; четыре напоминания из коробки, свои можно добавлять, переименовывать, удалять | Еда, тренировка и теория идут одним кодом; новые напоминания не требуют релиза | Окно настроек сложнее (список, добавить, удалить), больше тестов | JSON, RFC 8259; папка %APPDATA% (FOLDERID_RoamingAppData) | Чуть выше A | Низкий | https://learn.microsoft.com/en-us/windows/win32/shell/knownfolderid |
| C. Список с расписанием RRULE (iCalendar): любые правила повторения | Максимальная гибкость, стандартный формат | Избыточно; сложный интерфейс правил, нужна библиотека, больше крайних случаев (переход на летнее время) | RFC 5545, Proposed Standard 2009 | Высокая | Средний: формат правил расходится по хранению и UI | https://www.rfc-editor.org/rfc/rfc5545#section-3.3.10 |

## Decision

B: список напоминаний двух видов, «каждые N минут» и «в заданное время по дням недели». При первом запуске в нём четыре напоминания: движение раз в час, еда, тренировка и теория на права. Пользователь может добавлять свои, переименовывать, включать, выключать и удалять их. Владелец принял рекомендацию: еда, тренировка и теория отличаются только названием, временем и днями, так что это один вид, а кнопки «добавить» и «удалить» к нему почти ничего не стоят.

## Consequences

- Настройки хранятся в одном JSON-файле `%APPDATA%\move-reminder\settings.json` с полем `schemaVersion`. При запуске приложение мигрирует старые версии файла и не трогает файл, который не может прочитать: откладывает его в сторону и начинает с настроек по умолчанию.
- Окно настроек показывает список с добавлением и удалением. Это немного больше UI и тестов, чем фиксированный набор.
- Как вести себя с напоминанием на время дня, пропущенным во сне (A-3), решает спецификация. Модель данных этого не ограничивает.
- Пересмотр: перейти на правила RRULE можно новым видом напоминания и миграцией по schemaVersion; это отдельный эпик, файл пользователя при этом сохраняется.
